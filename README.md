# 📱 CampusNews - Android Application

CampusNews is an Android application developed to provide students with important campus updates in one place. The application organizes information into three main categories: **Academic, Events, and Placements**.

## 🎯 Aim

To develop an Android application that provides students with important campus news and updates using **Activities, Fragments, Views, Intents, and Notifications**.

## ✨ Features

- 🏫 College logo and application title
- 👋 Welcome message
- 📚 Academic updates
- 🎉 College Events updates
- 💼 Placement updates
- 📰 News/update image
- 📖 Short description of each update
- 🔍 Read More option
- 📄 Complete article view
- 🔙 Back navigation
- 🔔 Notification containing the selected article title
- 🧩 Fragments for displaying different categories
- 🔗 Intent-based navigation between screens

## 🛠️ Technologies Used

- **Android Studio**
- **Java**
- **XML**
- **Android SDK**
- **Android Activities**
- **Fragments**
- **Intents**
- **Views**
- **Notifications**
